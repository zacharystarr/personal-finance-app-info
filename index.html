Personal Finance Analysis

A private, single-user, read-only tool used by its owner to analyze personal finances.

Purpose

The tool organizes the owner's authorized transaction, account balance and investment data to support spending summaries, cash-flow reviews and net-worth tracking. It uses Plaid for supported account connections.

Local application

The application runs locally on the owner's computer. It is not offered to customers and has no public sign-up or hosted financial dashboard. It does not initiate payments or trades.

About this page

This public website provides application information only. It contains no financial records, credentials, account access, login form, analytics or application backend. Bank authentication takes place through the applicable bank and Plaid connection flow, not through this website.
